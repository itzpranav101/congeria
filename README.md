# Congeria

A heist game made at Hack Club Haven Singapore (theme: BOUNCE BACK).

One bank, one cop, one wildcard. Harry robs Congeria Savings, Rosie answers the calls his noise makes, and Ben's dice decide whose side he's really on. Get caught by Rosie and you bounce back as her.

Play: https://itzpranav101.github.io/congeria/
